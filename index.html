BUILD 01

StageSpot

July 2026 – August 2026

A full-stack platform that connects performers with cafés and venues looking to host live performances — profile verification, gig postings, bookings, reviews, and search built around how performers actually get discovered.

  • Built with Next.js, TypeScript, Supabase and PostgreSQL end to end.
  • Role-based authentication and secure booking flows using Supabase Auth and Row Level Security.
  • REST APIs for performer, venue, booking and review management.
  • Gemini API for natural-language performer search, with keyword search as a fallback.
  • Deployed on Vercel with Supabase for auth, storage and the database.

BUILD 02

Bridge Simulator

August 2026

An interactive, browser-based bridge construction tool: design a bridge, then watch it get tested by real-time vehicle loads under an actual physics engine, not a scripted animation.

  • Built with React, TypeScript, Three.js and Rapier Physics.
  • Real-time structural behaviour and vehicle movement driven by a physics engine, not pre-baked.
  • Interactive building tools for multiple structural component types.
  • Rendering and simulation tuned for smooth interaction at frame rate.
